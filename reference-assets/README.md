# ATLAS NEWS — Reference Assets

Carpeta de insumos manuales para ATLAS NEWS.

Puedes dejar aquí material que sirva como referencia o fuente de trabajo para futuras iteraciones del proyecto, por ejemplo:

- imágenes (`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`);
- mockups y capturas;
- piezas de marca;
- ejemplos visuales;
- PDFs o documentos de referencia;
- otros archivos auxiliares que no pertenezcan al contenido editorial publicado.

## Regla de arquitectura

Esta carpeta **no forma parte del pipeline de publicación** y ningún archivo que se deje aquí debe consumirse automáticamente por Morning Package, Publicador, Audio, Instagram o Reel Maker salvo que exista una integración técnica explícita y revisada.

Su finalidad es funcionar como bandeja de referencia segura y desacoplada del producto publicado.

## Importante

No guardar secretos, tokens, credenciales ni información sensible en esta carpeta ni en ningún otro lugar del repositorio.
